# Initial Assessment

Answer in your own words. This is not a test; it helps identify what to study.

## Data

1. What is the difference between a row and a column?
2. What does a primary key represent?
3. When would you use a CSV file, and when would you use a database table?
4. What does a `JOIN` do?
5. What do you think is the difference between transactional and analytical data?

## Processing

1. What do ETL and ELT mean?
2. What problems can a date field have?
3. How would you detect duplicates?
4. Why is it useful to keep an untransformed copy of the data?
5. What would you validate after loading 10,000 rows?

## Platform

1. What do cloud and SaaS mean to you?
2. What is the difference between storage and compute?
3. Who should be able to read, modify, or share a dataset?
4. What is a development environment?
5. How would you know whether a process failed?

## Interpretation

- If several questions are new to you, start with module 0.
- If you understand data and SQL but not the platform, start with module 1.
- If you can already answer everything with examples, complete the labs as a review and
  move on to the POC.

Save a dated summary in `PROGRESS.md`; repeat the assessment at the end of the POC.
