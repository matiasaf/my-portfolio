# Essential Glossary

| Term | Brief explanation |
|---|---|
| Capacity | Compute resources that run Fabric workloads |
| Delta Lake | Table format built on files with transactions and metadata |
| ELT | Load first, then transform within the destination platform |
| ETL | Transform before loading into the final destination |
| Lakehouse | Combines the flexibility of a data lake with queryable tables |
| OneLake | The Fabric tenant's single logical data lake |
| Pipeline | Orchestrated flow for moving data and running activities |
| Notebook | Executable document containing code, text, and results |
| PySpark | Python API for processing data with Apache Spark |
| Semantic model | Business layer with relationships, measures, and analytical meaning |
| Direct Lake | Power BI mode that queries OneLake data without a traditional import |
| Medallion | Progressive organization of data into Bronze, Silver, and Gold layers |
| Fact table | Measurable events at a defined grain |
| Dimension | Descriptive context for analyzing facts |
| Grain | What exactly one row represents |
| Lineage | Trace of a data item's origin, transformations, and consumers |
